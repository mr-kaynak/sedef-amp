# Code of Conduct

Sedef Amp follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, critique code rather than people, and help newcomers.
Harassment of any kind is not tolerated.

Report unacceptable behaviour privately to the maintainers through the contact listed on the
GitHub profile of the repository owner. Reports are handled confidentially.
