# Security Policy

Sedef Amp runs inside other applications (DAWs), so crashes and memory-safety bugs matter.

Please report vulnerabilities privately via GitHub's "Report a vulnerability" (Security tab) rather
than a public issue. Include the host, OS, plugin format and steps to reproduce. We aim to respond
within a week.

The plugin does not access the network. The embedded UI only loads its own bundled files; external
links open in your system browser.
