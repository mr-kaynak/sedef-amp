# DSP notes

One page per module. Each page answers:

1. **What it models** and the musical intent.
2. **Signal flow** (a short ASCII diagram is enough).
3. **Control mapping**: how each 0..1 knob maps to internal quantities.
4. **References**: public papers, textbooks, open-source code (with licence). See ADR-0006.
5. **Tests**: what the unit tests assert.
6. **Known limitations / future work.**
